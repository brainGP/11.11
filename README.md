# A Little Box Full of Love

A self-contained Next.js Pepero Day gift experience. The box, sticks, crumbs, and transitions are drawn locally with CSS; no image service or backend is needed.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`. Deploy the project folder to Vercel with the default Next.js settings.

## Personalize

- Edit the eleven three-letter words and notes in `data/peperoMessages.ts`.
- Edit the final heading and letter in `data/finalLetter.ts`.
- The sound button starts off. It generates a quiet tone bed and small bite/opening cues locally after the visitor enables it.
